# 5단계 공적연금 자동 추정 구현·검증 기록

확인 기준일: **2026-11-08 (Asia/Seoul)**. 계산 가격 기준: **2026년 고정 가격, 세전**. 5단계만 구현했다. 6단계 자동 진행, Git 커밋·Push, Vercel 배포, 로그인·서버 저장·데이터베이스 추가는 하지 않았다.

## 1. 구현 결과와 기본정보의 한계

공무원연금·사학연금·국민연금을 구분하여 자동 추정한다. 기존 공식 조회 월연금 입력은 선택 사항으로 유지하며, 입력한 조회값이 있으면 기존 검증 경로를 우선한다. 조회값을 지우면 자동 추정으로 돌아간다. 오래되거나 잘못된 조회값을 자동 추정으로 몰래 대체하지 않는다.

**기본정보만으로 월연금액을 생성하지 않는다.** 호봉·승급월·최종 봉급표 금액으로 과거 재평가 평균소득, 소득재분배, 개인별 이행률을 객관적으로 확정할 자료를 확보하지 못했다. 대신 지원되는 경력의 인정기간 시나리오, 정상 개시연령·조건 충족일, 최초 지급대상월·공백기간을 계산한다. 부족한 기초자료는 닫힌 상세 설정에서 선택 입력한다. 연금 자체의 예상 월액을 직접 입력할 필요는 없다.

각 제도의 금액은 조건부 추정이다. 개인별 공단 지급액과 대조하지 않았으므로 화면·AI 요청문에 **외부 금액 검증 미완료**를 유지한다. 국민연금의 공식 표 일부와 산술 대조한 사실은 개인 지급액 검증과 구분한다.

## 3. 구현한 실제 산식

### 공무원·사학의 검증된 공통 구조

변수: `B0`는 2009년 이전분의 현가화된 평균보수월액, `A`는 개인의 재평가 평균기준소득월액, `R`은 공단 확인 소득재분배 반영 평균소득, `K`는 공단 확인 이행률/보정률(100% 입력은 1), `Y`는 구간 인정개월/12다. `K=1`이나 `R=A`를 기본값으로 만들지 않는다.

- 2009년 이전: 20년 미만은 `B0 × 2.5% × Y`, 20년 이상은 `B0 × [50% + 2% × (Y−20)]`.
- 2010~2015년: `A × K × 1.9% × Y`.
- 2016년 이후: 총 재직기간의 최초 30년에 한해 `K × [R × 1% + A × (해당 연도 지급률−1%)] × Y`. 총 재직 30년을 넘는 부분은 `A × K × 해당 연도 지급률 × Y`.
- 연도별 지급률: 2016~2020년 `1.878, 1.856, 1.834, 1.812, 1.790%`; 2021~2025년 `1.780, 1.770, 1.760, 1.750, 1.740%`; 2026~2034년 `1.736, 1.732, 1.728, 1.724, 1.720, 1.716, 1.712, 1.708, 1.704%`; 2035년 이후 `1.700%`.
- 2016년 기준 인정기간이 21년 이상/17년 이상/15년 이상/그 미만이면 전체 상한은 각각 33/34/35/36년이다. 중단 없는 경력에 대해 이른 연도부터 배분한다.
- 2016년 이후분에는 종전 1.9% 방식의 잔여 33년 한도와 비교한 작은 금액을 적용한다. 공무원은 개정법 부칙 제13조제4항, 사학은 자체 2016년 개정 시행령 부칙 제3조를 근거로 한다.
- 승인 군복무는 실제 승인 개월과 산입연도가 필요하다. 2016년 이후 산입연도에 해당하는 지급률로 반영하며 실제 복무연도 지급률로 돌리지 않는다. 경과 상한이 바뀔 수 있으면 2016년 기준 공단 인정개월을 추가 요구한다.
- 내부 BigInt 유리수 합산 후 원 미만을 버린다. 이 직역연금 표시 끝수는 앱 계산 규칙이며 공단의 모든 급여 끝수 처리까지 검증한 것은 아니다. 구간별 표시액의 합과 최종 합계가 끝수 때문에 달라질 수 있다.

**지원 제한:** 2009년 이전분을 포함한 33년 초과 인정경력은 구법/신법 상한 배분과 비교조정의 검증이 남아 금액을 차단한다. 복잡한 합산·휴직·기수령 경력, 2015년 이전 군 산입도 금액을 생성하지 않는다. 입력된 특수경력 표시를 무시하고 일반 연속 재직식을 적용하지 않는다.

### 국민연금 별도 산식

`A=3,193,511원`, `B=공단 재평가 개인 평균소득`, `m_y=가입연도별 납부개월`, `c_y=비례상수`로 놓는다. 부양가족연금이 없는 일반 노령연금의 10~20년 지급률과 20년 초과 가산을 월액으로 전개한 식은 다음과 같다.

```text
일반 월액 = Σ[c_y × (A+B) × m_y] / 240 / 12
1988~1998년 항만 (A+B) 대신 (A+0.75B)
군 크레딧 추가 = 1.29 × (A+0.5A) × 확인개월 / 240 / 12
출산 크레딧 추가 = 1.29 × (A+A) × 확인개월 / 240 / 12
```

`c_y`: 1988~1998년 2.4, 1999~2007년 1.8, 2008년 1.5부터 매년 0.015 감소하여 2025년 1.245, **2026년 이후는 개정 1.29**다. 크레딧을 반영한 인정기간도 120개월 이상이어야 한다. 월액 상한은 `max(B, 가입 중 최종 5년 평균소득)`이며 필요한 최종 5년 소득이 없으면 금액을 요구 입력 상태로 둔다. 최종 10원 미만을 버린다.

실제 최초 납부월은 교사 임용일에서 가져오지 않는다. 기본 종료월은 퇴직월과 60세 도달 전월 중 이른 월인 **납부 계획**이며 실제 자격상실일 판정은 아니다. 마지막 납부월을 따로 지정할 수 있다. 이 사이 납부예외·체납·반환·추납 등이 없는 연속 납부만 지원한다. 정상 수급권 발생 뒤의 납부가 포함되는 경우 연기·임의계속가입을 자동 선택하지 않고 차단한다.

2026년 이후 크레딧은 공단 확인 개월만 반영한다. 군복무는 최대 12개월, 출산은 앱 입력 한도 1,200개월이며 이는 법정 상한을 새로 정한 것이 아니다. 2026년 이전 수급권의 크레딧 경과 계산은 지원하지 않는다. 공무원 군 산입 상태로 국민연금 크레딧을 자동 생성하지 않는다.

| 국민연금 | 실제 최초 납부월·마지막 납부 계획월, 재평가 B값, 상한에 필요하면 최종 5년 평균소득. 크레딧은 공단 확인 개월만 선택 입력 |
| 모든 추정 | 현재 임용일·퇴직일에 맞는 기초자료라는 확인. 두 날짜 중 하나라도 바뀌면 재확인 전 금액 차단 |

현재 기준소득월액을 쓰려면 별도 모드에서 **전체 가입기간의 재평가 평균소득과 같다고 가정한다는 동의**가 필요하다. 이는 법정 과거 소득 재평가 계산의 대체 구현이 아니라 고정소득 시나리오다. 직역연금의 R·K·구기간 B0는 이 동의로 만들어지지 않는다. 기존 퇴직수당용 소득도 연금용으로 묵시 재사용하지 않는다. 국민연금 현재 소득 시나리오에는 2026.7~2027.6 기준소득월액 41만~659만원 범위를 검사한다. 재평가 평균 B에는 현재 소득 상한을 일괄 적용하지 않는다.

## 5. 개시일·공백·조기연금

- 직역연금 1996년 이후 임용자의 일반 정상 개시연령은 재직 마지막 날이 속한 퇴직연도 기준: 2021년까지 60세, 2022~23년 61세, 2024~26년 62세, 2027~29년 63세, 2030~32년 64세, 2033년 이후 65세다. 10년 요건을 확인한다. 1995년 이전 임용자에게 이 표를 일괄 적용하지 않는다.
- 직역연금은 정상 조건 충족일이 속한 달이 최초 지급대상월이다. 그 달이 재직기간에 포함되면 그 다음 달로 미룬다. 예: 3월 1일 퇴직·즉시 요건 충족은 3월, 3월 2일 퇴직은 4월. 퇴직 후 5월에 연령 도달하면 5월이다.
- 국민연금 정상연령: 1952년 이전 60세, 1953~56년 61세, 1957~60년 62세, 1961~64년 63세, 1965~68년 64세, 1969년 이후 65세. 연령·120개월 요건 충족일의 다음 달이 최초 지급대상월이다. 교사 퇴직 전에도 가능하다.
- 자동 추정의 공백은 퇴직일부터 **최초 지급대상월 1일**까지의 일수와 완료 개월 수다. 실제 입금일이 아니다. 퇴직 전에 이미 수급하면 공백은 0이다. 기존 조회값에서 사용자가 별도 입력한 개시일은 그 입력일 기준으로 구분한다.
- 조기연금은 가능 조건만 안내하고 실제 신청을 선택하지 않는다. 직역연금 최대 5년·연 5%(최대 25%), 국민연금 최대 5년·월 0.5%(연 6%, 최대 30%) 감액이다. 국민연금은 소득 있는 업무에 종사하지 않는 등 별도 조건이 있다. 조기 감액액과 세금·재취업 지급정지는 계산하지 않는다.

## 6. 계산 예시와 신뢰도

| 조건 | 결과 | 검증 구분 |
| --- | --- | --- |
| 공무원/사학, 2016-01-01 임용~2027-01-01 퇴직, 132개월, A=R=400만원, K=100% | 월 788,240원 | 구성한 산술 사례. 공단 개인 지급액 대조 아님 |
| 위 경력에서 R=450만원 | 월 836,000원 | 종전 1.9% 비교 한도 적용 테스트 |
| 첫 사례에 군 24개월·2020년 산입 | 월 931,440원 | 군 산입연도 지급률 산술 테스트 |
| 2005-01-01 임용~2027-01-01 퇴직, B0=300만원·A=R=400만원·K=100% | 월 1,619,240원 | 세 구간 합산 산술 사례 |
| 국민연금, 모두 2026년 이후 납부, B=300만원, 10/20/30/40년 | 월 332,900 / 665,800 / 998,700 / 1,331,600원 | 공단 공식 2026 예상월액표와 일치 |
| 국민연금, 모두 2026년 이후, B·최종 5년 소득=41만원, 25년 | 월 410,000원 | 공식 표와 소득 상한 일치 |
| 기본정보만 있고 소득·계수 없음 | 금액 없음, 필요한 자료 표시 | 0원 또는 임의 월액 생성 금지 |

위 기간은 마지막 재직일을 포함하고 퇴직일을 제외한다. UI 테스트에서 2026-12-31 퇴직도 동일한 2016~2026년 132개 월을 사용하므로 첫 결과와 같다. 국민연금 40년 사례도 미래 A/B를 올리지 않는 **2026년 고정가격**이다.

금액 추정 신뢰도는 공단 확정이 아닌 조건부 수준이다. 공단 입력값의 진위, 미래 재평가·물가·소득 변화, 개인별 합산·감축·분할·세금·감액, 구법 장기경력 조정은 검증하지 못했다. 공식 표 대조는 국민연금 일부 대표 조건에 한정한다. **외부 금액 검증 미완료**는 모든 개인 추정에 남는다.

## 7. 05·06 및 기존 기능 연결

05에 제도·월액/추정 불가 사유·정상 개시연령·조건 충족일·첫 지급대상월·공백·가격 기준연도·방법·신뢰도·누락자료·출처를 표시한다. 추가 입력과 상세 산식은 접힌 영역에 둔다. 개인 금융자산과 공적연금 월액을 합산하지 않는다. 기존 계좌·공제회·명퇴수당·퇴직수당 계산과 6개 메뉴를 유지한다.

06에는 선택된 조회/추정 출처, 금액, 정상연령, 공백, 가정·산식·기간·신뢰도·외부 검증 상태·추가 확인사항을 반영한다. 미검증 금액을 확정 연금으로 표현하지 않는다. 익명 요청문에는 개인정보 날짜뿐 아니라 기준일도 연월로 표현하여 기존 정확한 날짜 감지와 복사 차단 규칙을 유지한다. 별도 고도화 단계인 8단계를 진행한 것은 아니다.

- `npm run test:browser`: **50/50 통과**, 데스크톱·모바일 각 25개. 새로운 공적연금 10개 포함. 로컬 프로덕션 서버에서 실행했다. 320px 화면 넘침·입력·제도 전환·요청문 복사·기존 01~06 흐름을 확인했다.
