# 2010년 이전 임용자 공적연금 산식 조사 (2026-11-20)

목적: 2010년 이전 임용 교원의 공적연금 월액이 계산되지 않는 원인을 법령 원문으로 확인하고, 계산을 허용하려면 무엇이 필요한지 정리한다. **이 문서는 조사 기록이며 계산 코드는 바꾸지 않았다.**

## 1. 현재 앱의 실패 지점 (실측)

가상 교원 579명 스캔(2026-11-20 기준, 기본정보만 입력):

| 임용 시기 | 월액 산출 | 차단 코드 |
| --- | --- | --- |
| 1995년 이전 | 0 / 48 | `PRE_2010_INCOME_REQUIRED`, `PAY_HISTORY_UNRECONSTRUCTABLE` |
| 1996~2009년 | 0 / 243 | `PRE_2010_INCOME_REQUIRED` |
| 2010~2015년 | 108 / 108 | — |
| 2016년 이후 | 180 / 180 | — |

1996~2009년 임용자에게 공단 확인 소득·적용비율·확인 날짜를 모두 입력해도(공무원·사학 각 55건):

- 정년퇴직: **0 / 56**
- 명예퇴직(총 재직 33년 이하): 26 / 54

원인은 [occupational-pension.ts](../src/lib/simple/occupational-pension.ts)의 `oldMonths && months > 396`(2009년 이전 재직분이 있는 33년 초과 경력 차단) 조건 하나다. 1996~2009년에 29세 이하로 임용되어 62세 정년까지 근무하면 거의 모두 33년을 넘는다.

## 3. 결론

1. **33년 초과 차단은 법령상 필요한 조건이 아니다.** 상한 배분(제24조, 최근 기간부터 제외)과 1.9% 비교(제13조제4항)를 지금 코드가 이미 구현하고 있다. 그 위에 별도 차단을 걸어 둔 상태다. 남은 불확실성은 "상한 초과 시 최근 기간부터 제외"의 공식 확인 하나다.
2. **공단 소득자료를 입력한 경로(확인 소득 경로)는** 차단을 풀면 바로 계산할 수 있다. 필요한 입력(B0, 평균기준소득월액, 재분배 소득, 적용비율)은 모두 공단 예상연금 조회 화면에 나오는 값이다.
3. **기본정보만으로 자동 추정하려면** 다음 자료가 더 필요하다.
   - 시행령 부칙 제10조제10항 2차원 표 전체(종전기간 열 포함) 전사
   - 2007~2009년 교원 봉급표와 당시 "보수월액" 정의(봉급만인지, 일부 수당을 포함하는지)
   - 연도별 현가화율 자료(누적 보수인상률, 전체 기준소득월액 평균)
   - 사학연금의 대응 부칙(사학은 시행령 2016년 개정 부칙 제3조 등 고유 규정) 대조

## 4. 구현 시 권장 순서 (승인 후)

1. **(2026-11-20 완료)** 확인 소득 경로의 33년 초과 차단을 제거하고, 상한 초과 개월을 최근 기간부터 제외한다는 안내 문구를 추가했다. 테스트를 추가했다.
   - 손계산 대조: 1999-01 임용·2035-12 퇴직, A=R=400만·B0=300만·적용비율 100% → 825,000 + 456,000 + 1,201,520 = 2,482,520원. 재분배 소득 450만이면 2016년 이후분이 1.9% 비교 상한 1,216,000원에 걸린다.
   - 2016년 전 재직 179/180/203/204/240개월 경계의 36/35/34/34년 상한(21년 이상 33년은 1995년 이전 임용 경로라 별도)
   - 재스캔: 1996~2009년 임용자에게 공단 자료를 입력하면 110/110건 산출(이전에는 정년퇴직 0/56건)
2. **(2026-11-20 완료, 2010년 이후 임용자 1건)** 공단 '현재예상 퇴직급여' 조회값과 대조했다.
   - 사례: 2016년 임용, 군 산입 26개월, III기간 155개월
   - 결과: 공단 905,680원, 엔진 905,684원, 끝수 처리 후 같은 값. 신규자 적용비율 84.62%와 종전 1.9% 비교 상한이 적용됐다. 조기연금 95~75% 다섯 행도 일치한다.
   - 공단 화면에 적용비율이 표시되지 않아도 비율이 적용된다는 점을 확인했다. 그래서 2010년 이후 공무원 임용자가 적용비율을 비워 두면 표 값을 자동 적용하고, 다른 값을 넣으면 안내한다.
   - 공무원연금 월액은 10원 미만을 버린다.
   - 상용 엑셀 계산기(교원용 통합프로그램 ver2027)는 같은 사례를 903,110원으로 계산했다. 재분배 소득을 자체 추정하기 때문으로 보이며, 엔진이 공단 금액에 더 가깝다.
   - 2009년 이전 임용자의 기본정보 자동 추정은 '준비 중'으로 표시한다(2007~2009년 보수 자료를 확보하지 못함). 공단 소득자료를 입력하는 경로와 공식 조회 월액 입력은 유지한다.
3. **엑셀·원문 대조로 남은 확인사항**
   - **(2026-11-20 수정 완료)** 신규자 적용비율 5개 값(2·6·11·24·28년차)이 2010·2013·2014년 시행령 원문 및 엑셀과 달랐다. 원문 값인 78.03·80.06·82.89·94.53·97.90으로 고쳤다([application-ratio.ts](../src/lib/simple/application-ratio.ts)).
   - 종전 1.9% 비교에 쓰는 재직기간: 엔진은 33년, 엑셀은 부칙 제24조 상한(34~36년)을 쓴다. 2009년 이전 재직분이 있고 33년을 넘는 경력에서만 결과가 달라진다.
   - 정확히 12의 배수 개월에서 적용비율 행 경계: 엔진과 공단 2020년 답변은 "초과~이하", 2010년 원문과 엑셀은 "이상~미만"으로 읽는다.
   - 상한 초과 개월을 최근 기간부터 빼는 처리는 엑셀과 같다.
4. 기존 계획: 공단 예상연금 조회 결과 1건 이상과 금액을 대조한다(사용자 실제 조회값 활용).
3. 자동 추정은 3절의 자료를 확보한 뒤 별도 단계로 진행한다.
