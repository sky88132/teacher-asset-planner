# 금융 경계 검증 수정 (2026-11-08)

최근 만원 단위 변경 이후 발견한 두 동작을 재현하고 공식 자료를 대조했다. 디자인·메뉴·입력 단위·데이터 모델·수익률 5/7/8%·복리와 반올림 계산·정년일 산정은 변경하지 않았다. 검증 범위와 안내만 수정했다.

## A. 짧은 기간의 연환산 한도 차단

### 공식 근거와 판단

[소득세법 시행령 제40조의2 제2항 제1호 가목](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033240359), 시행 2026-10-01, 대통령령 제36737호. 일반 납입금의 연간 기준은 1,800만원이며 계좌가 여러 개면 합계로 본다. 별도의 추가납입 특례가 있고, 제2호의 연금수령 개시 후 납입 제한도 구분해야 한다. 이 작업은 기존 개인 추가납입 시나리오의 일반 한도 판정에 한정하며 특례/연금 개시 후 납입을 새로 계산하지 않는다.

기존 검증은 실제 계획 기간에 관계없이 월액×12로 판정했다. 월200만원을 1회만 납입해도 차단했고 0개월에도 사용하지 않을 월액으로 차단할 수 있었다. 연간 제한을 구현하려는 의도는 타당하지만 일정과 무관한 12배 차단은 잘못된 검증이다.

### 처리

- 기존 완료 월·납입 시점 그대로 매 납입일을 계산한다. 오늘은 기준잔액만 사용하며 첫 납입은 `addSimulationMonths(today, 1)`이다.
- 계산 기간 내 실제 계획 납입일을 달력 연도별로 묶고, 두 계좌의 알려진 월 납입액 합계가 해당 연도에 1,800만원을 초과할 때 차단한다. 금액 합산은 BigInt로 오버플로를 방지한다.
- 0개월은 납입 0회, 1개월 월200만원은 2,000,000원의 1회 납입으로 계산한다. 연도별 한도 초과는 계속 차단한다.
- 12개월이 두 연도에 걸칠 수 있으므로 기간 전체 합계를 단일 연간 한도로 판단하지 않는다.
- 누락 계좌를 확인된 0원으로 만들지 않는다. 누락이 있으면 완전한 계좌 합계는 여전히 계산 불가다. 알려진 계획만으로도 한도를 초과하면 차단할 수 있다.
- 올해 기납입액·다른 계좌·상품별 설정한도·특례·연금 수령 개시 상태를 입력받지 않는다. 계획 계산이 허용된다고 실제 남은 납입한도나 적법한 납입 가능 여부를 인증하지 않는다. 이 제한을 화면 및 AI 요청문에 표시한다.

## B. 퇴직 전 연금 개시일 차단

### 공식 근거와 판단

[국민연금공단 노령연금 안내](https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0056M0.do?menuId=MN24001118)의 노령연금 수급 조건 및 소득활동에 따른 노령연금액 안내를 확인했다. 국민연금은 퇴직 여부만으로 수급을 결정하지 않으며 소득활동 중 수급과 감액 조건이 존재한다. 따라서 모든 제도에 퇴직일 이후 개시일을 요구한 것은 국민연금에 대한 잘못된 공통 제한이다. 개시일 입력 허용은 수급 자격 확인이나 감액 계산을 의미하지 않는다.

[공무원연금공단 급여내용](https://www.geps.or.kr/bizInformation_pensionBiz_GEPSystem_salaryDetails)은 일반 퇴직연금의 퇴직 요건을 안내한다. 공무원·사학 일반 퇴직연금의 기존 검증은 유지한다. 국가법령정보센터 공무원연금법 제43조 및 사립학교교직원연금법 제42조의 직접 링크는 이번 열람 시 본문 없이 외곽 화면만 반환했다. 사학의 모든 경과규정·재임용·별도 수급권 예외까지 재검증했다고 주장하지 않는다.

### 처리

- 국민연금 공식 조회값에 한해 퇴직일보다 이른 개시일을 허용한다. 조회값은 계속 사용자가 직접 입력하며 앱이 공단 조회나 진위 확인을 수행하지 않는다.
- 이전 개시일을 넣은 사용자 추정값은 공식 확인 안내와 함께 차단한다. 일반적인 같거나 이후 개시일의 기존 추정값 처리는 그대로다.
- 유효하지 않은 달력 날짜·출생일 이전 또는 같은 개시일·조회 가정 퇴직일 불일치·출처 및 세금 기준 누락 등은 계속 차단한다.
- 공무원·사학 일반 퇴직연금은 퇴직일과 같거나 뒤의 개시일을 사용한다. 재임용·별도 수급권은 간편 모드 지원 범위 밖이라는 이유를 구체적으로 안내한다.
- 퇴직 전 수령액을 적립금에 추가하지 않는다. 소득활동 감액·지급정지·퇴직 후 금액 변경·자격은 미검증이며 계산하지 않는다. 공식 조회 조건 확인 안내를 화면과 생성 요청문에 유지한다.

## 남은 위험 및 배포 상태

두 건의 잘못된 일괄 차단은 수정했다. 실제 잔여 납입한도, 공식 조회값의 진위, 국민연금 수급 자격/감액/정지, 공무원·사학의 특수 수급권 등은 계속 기관 확인 대상이다. 기존 미검증 연금/수당 자동 금액 계산은 활성화하지 않았다.

로컬 검사 기준 검토용 Vercel 테스트 배포를 준비할 수 있으나 실제 Vercel 환경·실기기·Safari는 이번에 확인하지 않았다. 커밋·Push·Vercel 배포를 수행하지 않는다.
