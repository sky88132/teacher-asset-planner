## 1~3 구현 결과

### 금액 표시

공통 `formatWonAsKoreanCurrency`를 표시 전용 정수 만원 반올림으로 변경했다. BigInt로 절대값을 반올림한 뒤 부호를 붙이므로 음수도 절댓값의5천원 경계에서 반올림한다. 억 경계도 반올림 후 분리한다.

- 173,423,613원 → `1억 7,342만원`
- 75,802,384원 → `7,580만원`
- 660,173,263원 → `6억 6,017만원`
- 99,995,000원 → `1억원`
- 실제0원 → `0만원`. 1원 등 반올림하면0인 양수/음수는 `0만원 초과~1만원 미만` / `-1만원 초과~0만원 미만`으로 실제0과 구분한다.

입력 문자열·만원 소수4자리·원 단위 계산과 BigInt 유리수 계산은 바꾸지 않았다. 입력 도움말의 정확한 환산은 유지한다. 화면 결과·표·그래프·조언과06의 금액을 같은 공통 함수로 표시한다. 요청문에 남긴100만원 개인정보 구간도 정수 만원 경계로 표시한다. 기존 `exact` 설정 키는 호환용으로 유지하지만 정수 만원 표시가 적용된다. 레거시 상세 엔진의 별도 원 단위 요청문 함수는 변경하지 않았다.

### 퇴직수당 참고 시뮬레이션

04에 기본으로 보이는 결과 카드와 접힌 `계산 근거 보기 (퇴직수당)`를 배치했다. 입력 소득이 있으면 기존2010년 이후 계산과 동일한 원 단위 결과를 사용한다. 공무원 소득 미입력 때는 개인 소득을 채우지 않고 별도 참고 결과를 만든다.

| 시나리오 | 2026년 기준소득월액 가정 | 의미 |
| --- | --- | --- |
| 보수적 | 476만원 | 전체 평균595만원의80%를 앱이 비교용으로 선택 |
| 기준 | 595만원 | 2026년 전체 공무원 평균. 개인·교사 평균 아님 |
| 높은 소득 | 714만원 | 전체 평균의120%를 앱이 비교용으로 선택 |

80~120%는 검증된 개인 분포·법정 최저/최고 지급범위가 아니다. 시나리오마다 가정 소득을 표시하고 `2026년 소득 수준 고정 가정`, 세전·개인 공식 조회액 아님·외부 금액 검증 미완료를 명시한다.

새 참고 결과는 `allowanceReference`로 분리했다. `q.income`을 임의로595만원으로 바꾸거나 기존 `allowance`/`benefitsTotal`을 덮어쓰지 않는다. 05의 기존 개인 추정·자산 합계는 그대로다. 06에는 참고 시나리오·기준소득·전체액 또는 이후분 소계와 미검증 조건을 별도 연결한다.

명퇴수당과 합산 가능한 경우에는 카드 안에 `동일 가정 기준 참고 합계`로 따로 표시한다. 두 항목의 공통 기준은2026년 가격·동일 퇴직일·세전이며, 명퇴는 호봉·봉급표 기준, 퇴직수당은 입력/통계 소득 기준이라는 차이를 안내한다. 이 합계를 기존 금융자산·개인 수당 합계에 재합산하지 않는다.

### 2009년 이전/2010년 이후

공단 공식 표에 따라 전체 인정기간으로 지급률 구간을 고른 뒤 기간별 기초소득과 지급률을 분리한다.

- 구기간: 공단 확인 최종보수월액 **현가액(2026년 기준)** × 구기간 인정연수 ×10%/35%/45%/50%/60%.
- 이후분: 기준소득월액 × 이후 인정연수 ×6.5%/22.75%/29.25%/32.5%/39%.
- 총 인정기간 상한396개월(33년), 연속 경력에서는 이른 구기간부터 상한을 배분한다. 총 재직연수 기준 지급률을 쓰며 구간마다 각각 근속기간을 새로 세어 지급률을 낮추지 않는다.
- 구기간 소득을 현재 호봉·현재 기준소득·595만원에서 역산하지 않는다. 별도 선택 입력과 현재 임용일·퇴직일 확인이 필요하다. 이 자료가 없으면 전체액은null이고 계산 가능한2010년 이후 소계만 명확히 따로 표시한다.
- 감축이 있으면 어느 구간에서 줄었는지 알 수 없어 구기간 자동 배분을 중단한다. 변경된 임용일·퇴직일의 기존 확인은 무효화한다. 군복무 승인만으로 퇴직수당 기간을 가산하지 않는다.
- 1991년 이전 경력의 종전 급여 보장 등 경과조건은 미검증이므로 구기간 전체 참고액을 제공하지 않는다.
- 사학2010년 이후 실제 소득 경로는 유지한다. 전체 공무원 평균을 사학 소득으로 자동 대체하지 않는다. 사학 구기간 현가화·경과규정 전체 금액 검증이 남아 신규 구기간 전체액은 보류한다. 국민연금에는 이 수당식을 적용하지 않는다.

기존 `estimateAllowance`의 구기간 개인 추정 차단은 유지한다. 새로 검증한 제한된 구기간 참고 경로를 별도 제공하며, 기존 산식 곱셈을 `allowanceAmount`로 추출해2010년 이후 경로와 중복 구현하지 않았다. 원 미만 버림은 기존 앱 규칙이고 기관 끝수 검증 완료를 뜻하지 않는다.
