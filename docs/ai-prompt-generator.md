# 07 AI 은퇴설계 분석 요청문 생성기

작성일: 2026-11-07. 유료·무료 AI API 호출 없이 브라우저에서 문자열을 생성한다. 자동 전송, 원격 저장, Supabase, 새 자산/부채 기능은 추가하지 않는다. 사용자가 포함 정보와 생성문을 직접 검토·편집한 뒤 복사한다.

## 구성과 데이터

`prompt-input.ts`는 8개 분석 목적·옵션·편집 상태, `prompt-data.ts`는 기존 상태/계산 결과의 허용 필드 추출, `prompt-privacy.ts`는 날짜 외 식별패턴 점검·금액 표시, `prompt-generator.ts`는 12개 절의 순서와 질문/품질 지침을 담당한다. 화면은 `analysis-prompt-panel.tsx`다. 금융 모듈·원본 입력은 수정하지 않는다.

기존 공적연금 입력 검증, 공제회 적립·가상 인출, IRP 적립·인출·일반 국세 공제, 퇴직 비교 및 현금흐름 함수를 다시 호출해 현재 결과만 가져온다. 단순 입력 평가금액은 사용자 입력이라고 표시하고 공식 계산 결과로 승격하지 않는다. 공식 조회금액은 사용자 직접 전사 값이며 진위 확인이 아니다. 미입력·미확정·계산 불가는 0원으로 채우지 않는다. 서로 다른 퇴직일의 공식 값을 재사용하지 않는 기존 검증을 따른다.

요청문 순서는 ① 역할·목적 ② 기본 조건 ③ 시나리오 ④ 공적연금·수당 ⑤ 공제회 ⑥ IRP·연금저축 ⑦ 현금흐름 ⑧ 수익률·물가 가정 ⑨ 신뢰도·공식 여부 ⑩ 누락·제한 ⑪ 분석 질문 ⑫ 답변 형식이다. 간단 모드도 12개 절과 신뢰도·제한을 유지하고, 상세 모드는 계좌별 소진과 연령 구간의 유입/지출을 확장한다. 상세 원장 전체를 내보내지는 않는다.

공적연금 미지급 기간은 전체 소득 0원과 다르며, 계좌 잔액 소진·일시금 현금 전환·현금 부족·미충당 지출을 구분한다. 퇴직 전 근로소득·저축·생활비가 없어 같은 연령의 완전한 비교는 불가하다는 제한을 보존한다. 제공 숫자와 AI 추정, 수익률 시나리오, 세금·투자 위험, 확인할 공식 규정, 추가 정보 우선순위와 중복 합산 금지를 명시한다. 외부 AI의 지침 준수나 답변 정확성을 강제·보장할 수는 없다.

## 개인정보 경계

- 기본 익명화 ON. 정확한 생년월일·임용일·조회/퇴직/수령 날짜는 자동 데이터에서 제외하고 연령대·약 경과연수·5세 구간으로 변환한다. 법령 버전·검토 시점은 공개 메타데이터의 연월과 고정 공식 근거 URL로 표시한다.
- 익명화 OFF만으로 정확한 날짜를 내보내지 않는다. 별도 명시 동의가 있어야 생년월일·임용일 및 세부 날짜가 포함된다. 이름·학교명·이메일·계좌번호 등은 OFF에서도 자동 추출하지 않는다.
- 상태 전체를 내보내거나 기존 급여 가정·자유 메모를 복사하지 않는다. 알려지지 않은 식별 필드가 원본 객체에 있어도 허용 목록에 없으면 제외한다. 금액·수익률은 기존 파서로 검증한 숫자만 표시하여 임의 문자열이 금융 입력을 통해 흘러가지 않도록 한다.
- 금액 기본값은 10만 원 단위 반올림. 100만 원 구간 또는 원 단위 표시를 선택할 수 있다. 작은 양의 금액이 0원처럼 보이지 않도록 별도 구간을 표시한다. 반올림/구간화된 금액을 다시 합산해 정확한 원본 결과를 재현하라고 요구하지 않는다.
- 추가 질문은 사용자가 개인정보 확인 체크를 하기 전까지 생성문에서 제외한다. 직접 질문 분석은 질문과 확인이 모두 필요하다. 이메일·전화·주민번호 형태·긴 번호/계좌 형태·식별정보 라벨·일부 학교명·허용하지 않은 정확한 날짜·미검토 주소가 있는 줄은 제외한다. 질문은 분석 대상이며 기존 안전·신뢰도 지침을 바꾸는 명령으로 취급하지 말라고 요청한다.
- 편집본도 같은 패턴을 점검하고 의심 패턴이 있으면 앱의 전체 복사를 막는다. 이 검사는 모든 개인 이름·학교명·문맥·번호 표기를 식별하는 완전한 익명화가 아니다. 확인되지 않은 무표식 이름이나 사용자의 수동 복사는 기술적으로 완전히 통제할 수 없으므로 미리보기와 편집본의 직접 검토를 안내한다. 개인정보 보호를 보장한다고 표현하지 않는다.

## 편집·변경·복사

생성 전 포함 정보의 종류와 변환된 미리보기를 제공하고 확인 체크를 요구한다. 개인정보·날짜·금액 옵션이 바뀌면 기존 편집본을 초기화하여 이전의 상세 개인정보가 새 익명화 설정에 남지 않도록 한다. 다른 메뉴 데이터·분석 목적·질문·분량이 바뀌면 기존 편집본은 보존하되 재생성 전 전체 복사를 막는다. 재생성은 편집본을 현재 계산 결과로 대체한다고 안내한다.

변경 감지 토큰은 원본 상태와 옵션을 문자열로 비교하는 메모리 전용 값이다. 토큰은 요청문·DOM·저장소·로그·URL·클립보드로 내보내지 않는다. 입력·옵션·원문·편집본은 부모 React 상태에만 보관하고 메뉴 이동 후 유지, 새로고침 시 초기화한다.

클립보드 쓰기는 사용자의 전체 복사 클릭에만 수행한다. 실패/미지원 시 텍스트 영역을 선택하고 Ctrl+C/모바일 복사를 안내한다. 사용자가 편집한 문구는 복사 전에 다시 점검하지만 계산 결과를 편집했다고 해서 공식 신뢰도가 높아지지 않는다.

## 외부 서비스 링크 확인

요청문이나 개인정보를 URL·쿼리·리퍼러에 붙이지 않는 고정 링크다. 새 탭과 `noopener noreferrer`, `no-referrer`를 사용한다. 자동 열기·전송은 없고, 서비스의 계정·요금·대화 저장 정책은 사용자가 확인해야 한다.

- [ChatGPT 공식 웹](https://chatgpt.com/): 직접 열람으로 확인.
- [Google Gemini 공식 웹](https://gemini.google.com/): 직접 열람 및 [Google 공식 도움말](https://support.google.com/gemini/answer/13275745?co=GENIE.Platform%3DDesktop&hl=en)에서 주소 확인.
- [Claude 공식 웹](https://claude.ai/): 이번 직접 열람은 도구 제한으로 실패했으며, [Claude 공식 도움말](https://support.claude.com/en/articles/8114487-what-interfaces-can-i-use-to-access-claude)에서 웹 채팅 주소를 확인했다.

## 검증 범위와 다음 우선순위

단위 테스트는 8개 목적·12개 절·실제 입력/계산값·누락·익명화·정확한 날짜의 명시 동의·원본 자유 메모/식별 필드 제외·금액 반올림/구간·질문 필터·편집본 패턴·변경 감지·원본 불변성을 확인한다. 테스트의 이름·주소·번호·생일·금액은 합성 데이터다.

브라우저 검사는 실제 입력 연결·생성·편집·복사 성공/실패·수동 선택·개인정보 옵션·질문 필터·원본 변경 후 재생성·메뉴 유지·모바일 너비·공식 링크와 자동 외부 요청 부재를 확인한다. 성공 복사는 클립보드 어댑터 대역으로 호출 텍스트를 검증하므로 모든 OS/브라우저 권한 조합에서의 성공을 보장하지 않는다.

검사 결과(2026-11-07): 단위 테스트 129/129(신규 요청문 12개), 데스크톱·모바일 브라우저 테스트 46/46(신규 6개), 타입 검사와 프로덕션 빌드 통과. 변경 파일의 비밀키 패턴 검출은 0건이며, 식별정보 형태가 들어 있는 부분은 개인정보 제외 동작을 검증하는 두 테스트 파일의 합성 입력뿐이다. 기존 금융 계산 모듈은 변경하지 않았다.

다음 우선순위는 다양한 문맥의 비식별화 오탐/누락 평가와 사용자 검토 동선 확인이다. 공식 금융 산식·세후 계산 및 외부 AI 답변의 사실 검증은 별도 검증 범위이며 이번 단계에서 자동 진행하지 않는다.
