# 가상 교사 100명 자동 검증 보고서

검증 기준일: 2026-11-09. 모든 자료는 고정된 **가상 데이터**이며 실제 교사·공단 조회 자료가 아니다. 이번 작업은 기존 계산 가정에 대한 산술·연동·입력 검증이다. 실제 연금·급여 지급액의 법적 정확성 검증과 구별한다.

## 1. 테스트한 가상 사례 수

- `tests/fixtures/synthetic-teachers-100.json`의 SYN-001~SYN-100, 총 100명을 실제 실행했다.

## 4. 발견한 오류

- 이번 범위에서 새로 확정된 앱 코드 오류는 없다. 음수 적립금, NaN/Infinity, 의도하지 않은 10,000배 변환, 월연금의 적립금 합산, 확인되지 않은 급여액의 0원 대체가 검증에 걸리지 않았다.
- 최초 100명 실행에서는 검증 코드가 2월 29일 퇴직일을 다음 해에도 그대로 만들어 4건이 실패했다. 앱이 존재하지 않는 날짜를 차단한 정상 동작이었다.
- 테스트 구성 점검 중 직접 소득 입력 경로에 치우쳐 교원 보수 기반 미래 퇴직급여 경로가 실행되지 않는 점을 발견했다. 일부 가상 사례를 미입력 소득 경로로 조정하여 실제 11명에서 해당 시나리오를 검증했다.
- 위 항목은 테스트 작성·구성 문제이며 기존 금융 계산의 오류나 수정으로 집계하지 않는다.

## 5. 수정한 오류

- 검증용 퇴직일 변경 시 윤년 2월 29일을 다음 해의 유효한 월말로 보정했다. 관련 4명을 다시 확인하는 회귀 테스트를 추가했다.
- 앱 계산식·검증 규칙·수익률·날짜 산정·모델·화면은 수정하지 않았다.

## 6. 추가된 테스트와 독립 검증 방식

- 고정 사례 100개, 추가 경계 테스트 18개, 대표 12명×PC·모바일 24개 브라우저 테스트를 추가했다.
- 독립 검증 모듈은 앱 계산 함수를 import하지 않는다. 날짜를 하루씩 순회하여 승급 횟수·월말 납입일·연말 일시납을 산정한다.
- 계좌 복리는 일별 수익 계수를 역으로 누적하는 방식으로 검증하고, 앱의 납입 건별 원 단위 반올림 후 합산과 비교한다. 부동소수점 연산 방식 차이의 허용치는 납입 건수에 따른 원 단위로 한정했다. 최종 100명에서 관측된 IRP·연금저축 차이는 최대 **0원**이었다.
- 공제회는 월 유효이율 적용 → 이자 원 단위 반올림 → 월 납입 순서로 별도 검증한다. 5%는 공식 보장 수익률이 아닌 기존 시뮬레이션 가정이다.
- 봉급표 연 3% 증가와 호봉 승급을 별도로 계산하며, 담임·교직·급식 수당은 기존 고정 가정과 대조한다. 퇴직급여 참고 합계는 같은 시나리오 내 구성 금액 합계로 확인한다.
- 만원 변환은 문자열·BigInt 기반 독립 계산으로 확인한다. 빈 값과 0, 0.5만원, 1원 정밀도, 큰 금액·안전 정수 범위 초과를 구분한다.
- 경계 검사는 오늘 퇴직, 정년 이상 명퇴, 임용·출생·퇴직일 역전, 잘못된 호봉, 승급 당일, 납입 0개월·0원, 연말납, 세액공제 대상 한도와 개인 납입한도 구분, 공적연금 개시가 퇴직 전인 경우, 미확인 수당, 오버플로 등을 포함한다.
- 브라우저는 6개 메뉴 이동·입력 유지, 실제 UI 결과와 계산 결과의 일치, AI 요청문 반영·정확한 생년월일/임용일 제외·복사, 모바일 390px 및 320px 가로 넘침, 브라우저 오류, 외부 요청과 쓰기 요청이 없는지 확인한다. 기존 브라우저 회귀 테스트도 함께 실행한다.

## 7. 공식 계산 검증이 필요한 항목

- 공무원·사학연금의 구기간 소득, 소득 재평가, 재분배 계수, 인정 경력, 지급정지·감액은 실제 개인 이력과 공단 확인이 필요하다. 현재 호봉이 실제 연금액을 확정하지 않는다.
- 국민연금의 실제 가입·납부·예외 이력, 소득자료와 기관별 정년일은 별도 확인 대상이다.
- 봉급 3% 상승, 담임수당 계속 수령, 일반 수당의 월평균 소득 대용치는 미래 가정이다. 실제 기준소득월액의 법적 산정을 검증한 것이 아니다.
- 명퇴 선정 여부, 사립학교 지급 조건, 휴직·군복무·합산 경력과 실제 퇴직수당 인정기간, 세전·세후 금액은 공식 자료와 개인 조건 확인이 필요하다.
- 공제회 적립·분할급여의 실제 상품 지급 방식, IRP·연금저축 환급액·수령한도·세후 지급액은 자체 시뮬레이션 통과와 구별한다. 세액공제 재투자는 기존 충분한 공제 여력 가정으로 검증했다.
- 미래 명목 금액과 2026년 기준 참고 금액, 월연금과 일시금, 전체 은퇴 현금흐름의 완전한 비교는 서로 대체할 수 없다. 기존 미검증 범위를 활성화하지 않았다.
- 이번에는 새로운 법령 해석이나 공식 숫자 사례를 확보하지 않았다. 기존 조사 문서와 테스트를 유지했으며 새로운 공식 지급액 검증 완료를 주장하지 않는다.

## 10. 전체 테스트 결과

- TypeScript: 통과.

- 프로덕션 빌드: 통과, 정적 페이지 생성 완료.
- 대표 사례 브라우저 최초 실행: **24개 통과**.
