# 교원 보수·공적연금·퇴직급여 참고 합계 개선

최초 구현 기준일2026-11-08, 유지보수 재검증2026-11-09. 실제 사용자 자료를 수집/복제하지 않고 가상 교사만 테스트한다. 초기 구현 당시 커밋·Push·배포 없음. 후속 저장 결과는 최종 유지보수 보고서 참조. 기존6메뉴·디자인·만원 입력/원 계산·기존 개인 입력·공식 조회 경로·금융 적립 엔진은 보존한다.

## 구현 계획과 경계

1.2026 공식 봉급표를 재사용해 현재 호봉에서 매년 승급월1일 승급(40호봉 상한), 별도로 봉급표만 연3% 상승시키는 표준 보수 모델을 만든다. 담임20만원·교직25만원·정근/가산금·명절휴가비·급식비16만원을 분리한다. 급식비는 비과세로 과세 보수 및 연금 기초에서 제외한다. 가족·보직·특수·성과/초과근무의 미확인 금액을 임의 입력하지 않는다.
2. 모델은 실제 급여/공식 기준소득이 아니다. 정기 수당과 연2회 수당을 구분하고 부분 연도는 근무월/연환산을 구분한다. 과거 실제소득이 없으면2026 봉급표와 역산한 호봉으로 만드는2026 보수수준 대체 경로임을 밝힌다. 이를 과거 실제 봉급표/법정 재평가 자료로 표현하지 않는다.40호봉의 과거 경로처럼 역산 불가능한 조건은 평균소득 자동 추정을 보류한다.
3. 기준소득 규정은 전년도 보수·비과세 제외·직종별8개 수당 평균·5월 적용/급여사유 예외를 갖는다. 공개된 교원별8개 수당 평균이 확인되지 않아 모델에는 확인 가능한 표준 보수 기초만 반영하고 미포함액은 미확인으로 남긴다. 정확한 기준소득월액이라고 표시하지 않는다.
4. 공무원2010년 이후 일반 연속경력에서 표준 소득 경로와 공식 연도별 지급률·신규자 이행률 표·재분배 구간표·재직 상한·종전급여 비교를 기존 연금 엔진에 연결한다. 재분배 비교A는2026 전체 평균595만원을 퇴직 전3년 평균의 대리 가정으로 사용할 뿐, 실제3년 평균/개인 소득으로 간주하지 않는다.90/100/110% 소득 민감도는 앱의 비교 가정이며 법정/통계 최저최고가 아니다. 법정 구조를 쓰더라도 결과는 가정 기반 시뮬레이션이다.
5.2009년 이전 보수·이행률·군 산입/복잡한 경과 이력이 불명확하면 전체 연금을 생성하지 않는다. 기존 확인 입력 경로와 정상 개시일 계산은 유지한다. 사학/국민연금에 새 공무원 교원 모델을 자동 적용하지 않는다.
6. 수당은 기존 산식을 재사용한다.2026 소득 기반 기존 참고 합계와 교원 보수 기반 미래 명목 합계를 별도로 표시한다. 원 합산 후 만원 표시. 구기간 미래 현가 기준을 만들 수 없으면 미래 전체 합계 보류. 월연금은 목돈 합계에 더하지 않는다.
7.05/06에 출처·연3%·담임 계속·표준 수당·미확인 요소·2026 환산과 미래 명목을 연결한다. 기본 화면은 간결하게 유지하고 근거/연도별 정보는 펼침에 둔다.2026 환산은 봉급상승 가정으로 환산한 비교액이며 물가할인에 따른 구매력 현재가치가 아니다.
8. 단위·경계·브라우저·모바일·타입·프로덕션 빌드를 실행한다. 공식 구조와 실제 기관 개인 지급액 검증은 구분한다.

## 복구·최종 검증 결과 (2026-11-09)

중단 시점의 구현은 실제 존재했고 기존 단위315개도 재현 통과했다. 기존 작업을 초기화하거나 금융 기능을 새로 만들지 않았다. 교원 모델은 공무원 일반2010년 이후·연속 경력·군 산입 제외·소득 경로 역산 가능 조건에서만 제공하고, 공단 확인 소득·직접 조회 경로와 구분한다.

- 공식 2026 봉급표1~40호봉, 수당규정 별표2의 정근/가산금, 별표11의 교직25만원·학급담당20만원, 제18조의 급식16만원을 재확인했다. 인사혁신처 재분배 구간표와 시행령 부칙10조10항의 신규자 이행률33개도 대조했다. 일반 법정 구조 확인이며 개인 급여/수급 자격 검증은 아니다.
- 같은 해에는 봉급표 인상과 승급을 각각 한 번 반영한다. 퇴직연도가 직전 근무연도와 다른1월1일 경계에서 보수 월평균 전체를3% 올리던 오류를 수정했다. 봉급·정근/명절 발생분만 인상하고 담임·교직·정근가산 고정액은 유지한다. 가상 사례의 기준 소득 기초는9,929,017원에서9,912,217원으로 변경되며 실제 기준소득월액이 아니다. 같은 연도 결과는 유지한다.
- 자동 모델의 과거 소득은2026 표를 이용한 대체 경로다. 과거 실제 급여/공식 재평가 계수·실제3년 전체 평균·직종별8개 수당 평균은 확인하지 못했다.2026 환산은 물가 구매력 현재가치가 아니다.
- 보수적/기준/높은 소득 시나리오를04·05·06에 연결했다.2026 가격과 퇴직연도 미래 명목은 별도로 표시하고 같은 퇴직시점·세전 모델끼리만 참고 합계를 만든다. 월연금과 금융자산을 합산하지 않는다. 공식 조회가 있거나 오래된 입력이 있으면 자동 모델로 조용히 덮어쓰지 않는다.
- 타입·단위317개·프로덕션 빌드·실제 Edge PC/모바일128개 통과.1월1일 경계 단위2개 및 브라우저1개×2환경을 추가했다.320px에서 펼친 보수표의 페이지 넘침도 확인했다. 개인 공단 지급액과의 외부 대조·실기기·Safari는 미실행이다.
