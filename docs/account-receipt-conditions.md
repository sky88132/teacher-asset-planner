## 2. 계좌별 날짜·가입일 입력

03의 각 계좌 예상 적립금 아래에 수령 요약과 닫힌 상세 설정을 추가했다. 기본 잔액·월납/연납 입력과 만원 표시는 그대로다. 선택 입력인 **최초 계좌 가입일**은 계좌별 독립 상태이며 최초 교사 임용일로 채우지 않는다.

- 만 55세 도달일: 생년월일의 55년 기념일.
- 가입 5년 충족일: 실제 가입일의 5년 기념일.
- 일반 연령·기간 충족 예상일: 두 날짜 중 늦은 날.
- 퇴직일 기준 충족/미충족/확인 필요를 구분한다. 충족일은 실제 신청일·지급일이 아니다.
- 가입일이 없으면 “만 55세 이후 연금수령이 가능할 수 있으나, 가입기간 충족 여부는 추가 확인이 필요합니다.”를 표시한다.
- 실제 가입일은 출생 이후·오늘 이내의 유효한 날짜여야 한다. 윤일의 비윤년 기념일은 2월 말일로 처리한다.

금융기관이 실제 이연퇴직소득 보유를 확인했다는 사용자 선택과 실제 입금일이 모두 있어야 가입 5년 예외를 반영한다. 입금일 이전으로 소급하지 않고 55세 요건은 유지한다. 미래 퇴직급여 이체 계획은 실제 보유로 인정하지 않는다. 일반 5년 요건을 이미 충족한 경우 뒤늦은 퇴직소득 입금 때문에 충족일을 더 늦추지 않는다.

시행령 제40조의2의 예외는 이연퇴직소득이 있는 연금계좌에 관한 규정이므로 두 계좌 모두 확인된 재원 경로를 제공한다. 연금저축으로의 이체 등 별도 이력이 있으면 일반 모델을 중단하고 유효 가입일·경과규정 확인을 안내한다. 승계·계좌이체·구 개인연금 표시, 2001년 이전 가입은 자동 판정을 보류한다. 2001년 기준은 과거 상품을 안전하게 구분하기 위한 앱 지원 범위이며 새로운 법정 가입요건이 아니다.

## 3. IRP 재원과 기존 적립 엔진 유지

현재 IRP 계산은 사용자 입력 현재 평가액 + 향후 개인 납입금 + 가정 운용수익 + 선택적 환급 재투자다. 현재 평가액 자체의 재원은 알 수 없다. 이를 개인 납입금만 있는 사실로 확정하지 않고, 미래 납입 계획이 개인 납입 중심이라는 점을 구분한다.

04의 공무원연금법상 퇴직수당과 명퇴수당은 근로자퇴직급여보장법상 퇴직급여와 동일한 법적 재원으로 간주하지 않았다. 실제 이체 가능 여부·과세이연·지급 경로를 개별 검증하지 않았으므로 IRP에 합산하거나 5년 예외를 자동 적용하지 않는다. 입력 평가액을 계좌 유형별 재원 잔액으로 임의 분해하지 않는다.

`calculateAccount` 및 `account-schedule.ts`의 기존 적립 계산은 변경하지 않았다. IRP 7%·연금저축 8%, 실제 월말/연말 납입·복리·납입한도·환급 재투자는 유지한다. 수령 메타데이터는 별도 `account-receipt.ts`가 계산한다. 수령 설정을 바꿔도 적립금은 같다는 회귀 테스트를 추가했다.

개시 신청 이후 납입 제한이 있지만 이번 적립금은 **퇴직일까지 인출 없이 납입**하는 기존 시나리오다. 수령 개시 계획을 입력해도 적립금을 자동 변경하지 않으며, 계획한 수령과 기존 계속 납입을 동시에 실행할 수 있다고 안내하지 않는다. 개시 후 납입·중도 인출·남은 잔액의 현금흐름은 별도 설계가 필요하다고 표시한다.

## 4. 연금수령한도

독립 함수 `statutoryReceiptLimit`은 `기준 평가액 ÷ (11−한도용 수령연차) × 120%`를 BigInt 유리수로 계산한다. 표시·비교는 원 미만 버림으로 보수적으로 처리한다. 금융기관의 법정 끝수 처리까지 대조한 것은 아니다.

한도 계산에는 다음이 필요하다.

1. 유효한 계좌별 요건 충족일과 적용 과세연도(2026년 이후).
2. 실제 또는 사용자가 계획한 개시 신청일. 자동으로 퇴직일을 넣지 않는다.
3. 신청연도는 신청일, 이후 연도는 1월 1일의 평가 기준일·평가액. 퇴직 예상 적립금이나 오늘 잔액을 자동 대체하지 않는다. 미래 평가액 입력은 사용자 가정이다.
4. 선택적인 해당 연도의 누적·예정 한도 산입 세전 인출액. 과세제외 및 법정 의료비·부득이 인출 등은 금융기관 확인 후 제외한 금액이다. 전체 현금 인출의 재원 분해를 대신 계산하지 않는다.

한도용 수령연차는 최초 연령·기간 요건 충족 과세연도부터 계산하며 신청을 늦춰도 초기화하지 않는다. 2013-03-01 **이전** 가입은 6년차 기산, 경계 당일부터 일반 1년차다. 2013년 이전에 이미 요건을 충족한 계좌, 구 DB 이력에 따른 특례·승계·이체는 경과 기산을 임의 추정하지 않고 기관 확인을 요구한다.

1~10년차는 산식을 적용하고 **11년차 이상은 한도 계산식 미적용**으로 표시한다. 무한대·0원 한도로 대체하지 않는다. 10년차 산식이 평가액의 120%인 것과 실제 잔액을 초과해 지급받을 수 있다는 것은 다르다. 한도 이내·초과분을 별도로 표시하지만 의료비 특례·잔액·계약·인출순서 심사를 대신하지 않는다.

예: 평가액 1억원, 일반 1년차면 한도 1,200만원. 한도 산입 인출 예정액 1,500만원이면 이내 1,200만원/초과 연금외수령 300만원. 6년차 한도는 2,400만원이다. 실제 세전 수령액을 이 한도만으로 자동 결정하지 않는다.

## 5. 재원별 세금·2026 변경

| 재원 | 적격 연금수령 | 일반 연금외수령 |
| --- | --- | --- |
| 공제받지 않은 납입금 | 증빙 확인 후 과세제외 | 과세제외 |
| 공제받은 납입금 | 연령·계약에 따른 연금소득 과세 | 기타소득 국세 15%·지방세 포함 16.5% |
| 운용수익 | 위와 같은 연금소득 구분 | 일반 기타소득 16.5% |
| 이연퇴직소득 | 별도 연금소득 분리과세, 실제 수령연차별 퇴직소득세 비율 | 감면 없는 퇴직소득세 |

연령별 국세 원천징수는 70세 미만 5%, 70~79세 4%, 80세 이상 3%이며 지방세 포함 5.5%/4.4%/3.3%로 안내한다. 2026년부터 중도해지 불가 종신계약은 국세 3%(지방세 포함 3.3%)이고 중복 조건에서는 낮은 세율이다. 앱이 일반 계좌를 종신계약으로 전환한 것은 아니다.

2026년 이후 이연퇴직소득은 실제 수령연차 1~10년/11~20년/21년 이상에 일반 퇴직소득세의 70%/60%/50%를 적용한다. 수령액 자체에 이 비율을 곱해 세금을 계산하지 않는다. 실제 수령한 과세연도만 합산하며, 한도용 연차·가입기간·현재 나이로 대체하지 않는다. 상세 설정에서 금융기관 확인 실제 연차를 선택 입력받아 비율만 안내하고 세액은 만들지 않는다. 이체·중복 이력의 실제 연차 산정은 금융기관 확인이 필요하다.

과세대상 사적연금은 이연퇴직소득 등 별도 구분을 제외한 전 금융기관 합산 연 1,500만원을 확인해야 한다. 초과 시 종합과세 또는 국세 15%(지방세 포함 16.5%) 분리과세 선택·신고가 관련된다. 단일 계좌 총인출이나 공적연금까지 모두 더해 기준을 자동 판정하지 않는다.

개인의 세액공제 이력·재원별 잔액·이연퇴직소득세·타 연금·다른 소득 등이 없으므로 `netWon=null`을 유지한다. 의료비·부득이한 인출의 증빙·기간 요건과 공제받지 않은 납입금 입증도 따로 확인해야 한다. 원천징수율이 최종 세후 수령액을 보장하지 않는다.

## 6. 05·06 연결

05에는 기존 IRP·연금저축 예상 적립금과 공적연금 결과를 유지하고, 계좌별 요건 충족 예상일·퇴직일 기준 상태·공백 중 활용 검토 가능 여부를 추가했다. 공백 계산의 기존 공적연금 개시 기준을 재사용한다. 개인 계좌 요건이 공백 중 충족되면 검토 가능, 이후 충족이면 일반 요건 활용 어려움, 정보가 없으면 확인 필요로 구분한다. 퇴직 전 공적연금 개시 때는 공백 없음으로 표시한다.

생활비·실제 인출 일정·세금·한도·잔액을 연결한 충당액은 이번 단계에서 산출하지 않는다. 계좌 전액을 자유로운 공백 자금으로 안내하지 않는다.

06에는 두 계좌 예상 적립금(기존 항목), 55세 도달·가입 5년·요건 충족 시점, 예외 보유 확인 상태, 신청·한도 기준, 세전 한도 산입 인출액·이내/초과, 세금 구분·필요자료·공백을 반영한다. 날짜는 기존 익명화 정책을 거친다. 개인정보 감지·복사 차단을 완화하지 않았다.
