# 04 퇴직급여 / 05 공적연금 표시 수정

작업일: 2026-11-09 (Asia/Seoul). 실제 사용자 입력은 열람·복사하지 않았으며 테스트는 기존 가상 교사와 가상 데이터만 사용한다. 커밋·Push·배포하지 않는다.

## 1. 합계 중복 원인

`SimpleBenefitsPanel`이 새 `BenefitReferenceTotals` 뒤에 구형 `benefitsTotal` 카드까지 렌더링했다. 새 합계는 교원 보수 또는 전체 공무원 통계 소득을 사용하지만 구형 합계는 `q.income`의 개인 입력값이 필요했다. 동일 화면에서 서로 다른 입력·가격 상태를 판단해 정상 참고 합계와 ‘완전한 합계 확인 불가’가 공존했다. 명퇴 결과 전체가 details 안에 있고 새 합계가 퇴직수당 카드보다 앞에 있었다.

## 2. 수정된 화면과 결과 선택

04는 명예퇴직수당 예상액 → 퇴직수당 예상액 → 참고 합계 순서다. 금액은 기본 노출, 산식·소득 입력·비교 자료는 접힌 근거 영역에 둔다. 퇴직수당 카드의 중간 합계와 구형 최종 합계 카드는 제거했다. 기존 공식 수당 산식을 재사용한다.

`calculateSimple().benefitReference`가 교원 미래 명목 시나리오를 우선 선택하고, 해당 모델을 사용할 수 없거나 개인 소득을 입력했다면 2026 가격 고정 참고 시나리오를 선택한다. 선택 결과는 퇴직일·가격연도·세전 기준과 각 시나리오의 명퇴/퇴직수당/합계를 포함한다. 04·05·06이 이를 함께 사용한다. 원 단위로 합산한 후 기존 만원 정수 형식으로 표시한다. 세후 조회값을 세전 수당과 섞지 않으며, 수당용 직접 조회액은 기존 자동 산식을 덮어쓰지 않는다.

기존 `benefitsTotal` 및 금융자산 계산을 변경하지 않았다. 이 값은 개인 입력 소득 기반의 별도 2026 가격 고정 경로다. 참고 합계가 확인 자산으로 바뀌는 것은 아니다. 공적연금 월액은 금융자산·일시금에 더하지 않는다.

## 3. 자동 공무원연금 차단 원인과 수정

`estimateTeacherPension`의 `hasIncome`이 평균소득·재분배소득·이행률 외에 `confirmedRetirementDate` / `confirmedAppointmentDate`까지 소득정보로 취급했다. 소득 없이 확인 체크만 해도 `eligible=false`가 되어 보수 모델이 차단되고, 확인 소득 전용 엔진의 필수자료 부족 상태가 노출됐다. 퇴직일을 변경해 날짜 확인값이 오래되어도 같은 문제가 발생했다.

날짜 확인과 실제 소득 입력을 분리했다. 확인 날짜만 있는 경우 교원 모델이 현재 기본정보로 소득을 다시 생성하고 기존 공무원연금 엔진에 전달한다. 실제 소득·계수 또는 현재소득 고정 모드를 사용자가 입력한 경우에는 그 경로를 유지한다. 직접 월연금 조회액은 유효성 검사를 거쳐 우선 표시하고 오래된 조회액을 자동 모델로 감추지 않는다. 모델 보류 시에는 모델 오류를 계산 결과와 화면에 연결하고 생성된 시나리오의 엔진 오류도 전달한다.

정상 수급조건 충족일·최초 지급대상월·공백 개월/일 계산은 수정하지 않았다. 월액이 없어도 기존에 산정 가능한 개시일과 공백은 유지한다.

## 4. 참고 추정의 범위와 소득 가정

기존 참고 모델을 활용했으며 새 법정 상수를 생성하지 않았다. 일반 국공립 호봉제 교원, 2010년 이후 신규 임용, 중단 없는 경력, 현재 호봉으로 과거 호봉을 역산할 수 있는 경우에 자동 적용한다.

- 2026 봉급표, 매년 승급월 1일 승급, 40호봉 상한. 봉급표 인상 연 3%와 호봉 효과는 각각 한 번 적용한다.
- 담임 월20만원 계속 수령, 교직 월25만원, 정근/가산·명절의 표준 보수 발생액. 급식 월16만원은 비과세 제외한다. 가족·보직·특수·성과/초과근무 등 미확인 개인/직종 평균액은 임의로 채우지 않는다.
- 연도별 보수 경로 → 2026 보수수준 환산 기초의 재직월 가중평균 → 개인 평균소득 기초 → 별도 소득재분배 기초 → 신규자 적용비율 → 2010~2015 / 2016 이후 연도별 지급률과 경과 상한·종전액 비교 → 정상 개시연도 명목 월액 순서로 기존 엔진에 연결한다.
- 전체 공무원 평균595만원은 개인 소득이 아니다. 기존 모델에서 퇴직 전3년 전체 평균의 대리 가정으로만 사용한다. 이는 미래 실제3년 평균이나 법정 확정값이 아니다.
- 과거 실제 급여와 법정 재평가 자료를 대신해 2026 봉급표·역산 호봉 경로를 사용한다. 미래 보수 및 재평가에 연3%를 가정한다. 2026 환산 비교액은 물가할인에 따른 구매력 현재가치가 아니다.
- 보수적/기준/높은 소득은 교원 보수 기초90/100/110% 민감도다. 법정 최저·최고 지급액이나 통계 신뢰구간이 아니다. 별도 전체 공무원 통계 비교 경로는80/100/120%를 사용하며 가격 기준을 구별한다.

## 5. 계산할 수 없는 경우

2009년 이전 평균보수월액은 2007~2009년 보수의 현가화 구조이고 기존 재직자 적용비율도 신규자 표와 다르다. 현재 모델의 과세 보수 기초만으로 두 변수를 대체할 수 없어 자동 전체 월액을 만들지 않는다. 화면에 부족한 변수와 이유, 상세 설정 입력 경로를 명시한다. 40호봉의 과거 도달 시점 불명, 역산 호봉 범위 이탈, 복잡한 휴직/합산 경력, 승인 군경력의 인정기간·산입연도도 별도 확인이 필요하다. 현재 확인 입력 엔진의 지원 범위를 넘는 33년 초과 구기간 경력 등은 기존 제한을 유지한다.
