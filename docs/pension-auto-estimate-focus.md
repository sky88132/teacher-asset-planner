## 1. 재현한 월액 차단 원인

- teacherStepAt은 현재40호봉이면 과거 모든 달에 null을 반환했다. 미래 보수는 계산돼도 historyErrors 때문에 연금 평균소득 전체가 보류됐다.
- estimateTeacherPension의 hasIncome이 구기간 보수·적용비율만 입력해도 교원 소득 모델을 껐다. 구기간 필수값을 확인해 입력했는데도2010년 이후 평균소득이 비어 확인 소득 엔진에서 멈췄다.2010년 이전 임용은 자료 유무와 무관하게 차단됐다.
- 정상 개시 조건 충족일·공백·가격 기준은 상세 펼침에 있어 월액과 함께 기본 화면에서 확인하기 어려웠다.

위 원인은 가상 사례로 재현했다. 실제 사용자의 입력 조건을 새로 추측하거나 복제하지 않았다. 이전 날짜 확인값 차단 수정과 공식 조회 우선순위는 남아 있었다.

## 2. 실제 계산 수정

teacher-pay.ts는 현재40호봉인 경우 가장 최근 정기승급일에40호봉에 도달한 것으로 계획 경로를 선택한다. 정기승급을 되돌려 공식 봉급표1~40호봉 범위에서 역산한다. 상한 도달 이력이 확인된 것은 아니며 더 일찍 도달했다면 과거 보수가 달라진다는 한계를 기본 화면·상세·AI에 표시한다. 초임호봉을 임의의 법정 상수로 채우지 않는다. 역산 범위 이탈은 계속 보류한다.

teacher-pension.ts는 실제 평균·현재·재분배 소득 입력과 구기간 보수·적용비율만 확인한 경우를 구분한다. 후자는 교원 모델의 평균소득과 결합해 기존 estimateCivilPension에 전달한다. 구기간에는 신규자 적용비율 표를 사용하지 않는다. 현재 임용일·퇴직일 확인이 오래됐거나 값이 잘못되면 기존 엔진의 검증 오류를 전달하고 금액을 선택하지 않는다.

구기간 입력 보수는2026년 가격 기준이다. 미래 명목 계산에서는 다른 소득과 같은 계획 환산율을 적용한다. 구기간 보수는 세 시나리오에서 같게 유지하고2010년 이후 소득 기초만90/100/110%로 변화시킨다. 기본가격과 미래 명목 결과가 모두 계산된 경우만 기준 결과를 선택한다.

기존 법정 구간식, 연도별 지급률, 재분배 구분, 인정 상한, 종전1.9% 비교 엔진과 연금 개시일 로직을 다시 작성하지 않았다.

## 3. 자동 추정 가능한 조건

- 일반 국공립 호봉제 교원, 표준 보수 모델 사용, 유효한 기본정보·호봉·승급월, 일반 연금 인정기간10년 이상, 지원 범위의 연속 경력.
-2010년 이후 신규 임용: 기존 신규자 적용비율 표와 교원 소득 모델로 추정. 현재40호봉도 명시된 계획 가정으로 추정.
-2010년 이전 임용: 구기간 평균보수 현가액·해당 경력 적용비율·현재 임용일/퇴직일 확인이 추가로 있는 경우 기존 엔진 지원 범위에서 결합 추정.
- 실제 평균소득·재분배소득을 입력하면 확인 소득 경로를 우선한다. 직접 월연금 조회액은 최우선이며 오래된 조회액의 오류를 모델로 감추지 않는다.

## 4. 여전히 보류하는 조건

- 구기간 평균보수 현가액 또는 기존 재직자 적용비율이 없는2010년 이전 경력.04 퇴직수당용 최종보수 현가액은 연금 평균보수와 다르므로 재사용하지 않는다.
- 역산 호봉이1~40 범위 밖인 경우, 휴직·시간제·중단·합산·기수령 등 별도 이력.
- 군 산입 승인만 있고 인정개월·실제 산입연도·경과자료가 없는 경우. 군 산입과 표준 보수의 자동 결합은 확장하지 않았다. 산입이 바꾸는 인정기간·상한과 소득 경로의 결합 검증이 남아 기존 확인 소득 경로를 사용한다. 승인만으로 복무개월을 가산하지 않는다.
-1995년 이전 임용자의 정상 개시 경과자료가 없거나, 구기간33년 초과 비교 검증이 남은 경우, 유효하지 않은 입력·기간 미달.

기존에 계산 가능한 정상 개시일·최초 지급대상월·공백은 유지한다. 사학·국민연금에는 새 공무원 교원 모델을 적용하지 않는다.

## 5. 공식 자료와 가정

- [공무원연금공단 안내](https://www.geps.or.kr/bizInformation_pensionBiz_pensionReceipt_receiptOverview_dateMethod): 구기간 평균보수,2010~2015 평균기준소득,2016 이후 재분배1%와 지급률 초과분, 개시 경과표 확인.
- [공무원연금법 시행령 공식 기관 보관본](https://www.nhis.or.kr/lm/lmxsrv/law/lawFullContent.do?SEQ=228&SEQ_HISTORY=): 제5조 기준소득, 제10조 환산, 제23조 군 산입절차, 제26조 전체 평균 확인.
- [2026 공식 봉급표](https://www.mpm.go.kr/mpm/info/resultPay/bizSalary/2026/)와 [정기승급 규정](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027304115)을 기초로 기존 보수 모델 재사용.
- [보수규정·초임호봉 구조](https://law.go.kr/lsInfoP.do?lsId=002298): 초임은 개인 경력·학력에 좌우되므로 특정 초임호봉을 법정 상수로 생성하지 않음.

봉급표 연3%와 호봉 승급을 각각 한 번 적용한다. 담임 월20만원 계속, 교직 월25만원, 정근/가산/명절 표준 보수 발생액, 비과세 급식비 소득 제외의 기존 가정을 유지했다.
연환산 표준 과세 보수 월평균은 실제 법정 기준소득월액이 아니다. 과거는2026 표 기반 대체 경로이며 실제 과거 봉급표·법정 재평가 자료의 복원이 아니다. 전체 공무원595만원 대리 평균과 교원 개인 추정 소득을 구별한다.
40호봉 최근 도달·연3% 미래 재평가는 계획 가정이다.90/100/110%는 법정 최저·최고나 실제 지급범위가 아닌 민감도 분석이다.2026 보수수준 환산은 물가할인 구매력 현재가치가 아니다.
