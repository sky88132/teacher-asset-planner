# 이전 7메뉴 UI 테스트 기록

6메뉴 간편 개편 이전의 브라우저 시나리오를 원문 그대로 보존한다. 이전 UI 컴포넌트는 소스에 남아 있으나 현재 라우트에 노출하지 않는다. 따라서 이 테스트는 현재 제품의 회귀 테스트가 아니며 기본 Playwright testDir(`tests/browser`)에서 제외한다.

현재 메뉴와 입력 계약은 `tests/browser/simple-planner.spec.ts`에서 검사한다. 기존 금융 계산 단위 테스트(`tests/*.test.mjs`)는 계속 실행한다. UI 기능을 제거한 것과 금융 엔진의 기존 단위 검증을 제거한 것을 구분한다.
