# 교사 은퇴 플래너 — 로그인 없는 간편 계산

Next.js·TypeScript 기반의 교사 은퇴 참고 시뮬레이터입니다. 기존6개 메뉴와 디자인을 유지합니다. 로그인·Supabase·DB·서버 저장·브라우저 저장소를 사용하지 않으며 입력은 React 메모리에만 유지됩니다. 새로고침하거나 창을 닫으면 초기화됩니다.

## 현재 메뉴

1. 교사 기본정보 — 세 연금제도, 생년월일·임용일·호봉·승급월·군복무 상태, 정년/명퇴일과 예상 퇴직 호봉.
2. 교직원공제회 — 현재 잔액·향후 월 납입, 연5% 고정 가정의 적립 및 일시금/5~30년 가상 분할.
3. IRP·연금저축 — 계좌별 월납/연말납, 연7%/8% 가정,13.2% 공제 참고액의 체크박스 재투자, 선택 가입일·수령 요건·한도·과세 안내.
4. 퇴직급여 계산 — 지원 조건의 명퇴수당·퇴직수당 자동 추정 및 개인 소득과 분리한 참고 시나리오. 산식·조건은 펼침 영역에서 확인합니다.
5. 은퇴설계 종합 — 핵심 요약·자산 카드·구성/월수입 그래프·소득 공백·세 범주 조언, 공적연금 조건부 추정과 선택 공식 조회액 입력.
6. AI 분석 요청문 — 선택 월 생활비(05와 공유),6개 분석 목적, 익명 미리보기·편집·복사. 기본정보만으로 생성 가능하며 외부 AI에 자동 전송하지 않습니다.

입력 단위는 **만원**, 내부 계산은 **원**입니다. 주요 결과와 요청문 금액은 정수 만원으로 반올림하며 반올림한 표시값을 계산에 재사용하지 않습니다. 미입력과 실제0원을 구분합니다.

## 계산 범위와 한계

- 공통 퇴직일을 변경하면 적립금·호봉·수당·수령조건·공백·조언·요청문이 갱신됩니다. 직접 조회액의 가정 퇴직일이 바뀌면 재확인이 필요합니다.
- 일반 초·중등62세·학기말 정년 및 제한 없는 정기승급은 조건부 가정입니다. 사립·대학·별도 신분·군복무·휴직·합산 이력은 실제 기관 자료가 필요합니다.
- 공제회5%·IRP7%·연금저축8%는 고정 계획 가정입니다. 공제회는 완료 월 모델, 연금계좌는 실제 월말/연말 납입 및 실제 일수의 연도별 복리 모델을 유지합니다. 실제 수익·상품 지급액·세후액을 보장하지 않습니다.
- 재투자는 공제 대상 한도(연금저축600만원·합산900만원)에13.2%를 적용한 참고액을 다음 해5월 말 IRP에 넣는 가정입니다. 충분한 세액 여력을 가정하며 개인별 실제 환급액·올해 기납입·다른 계좌·다른 공제는 미확인입니다. 연1,800만원 일반 납입한도를 검사하고 퇴직일 이후 입금은 제외합니다. 재투자금을 별도 현금자산으로 더하지 않습니다.
- 공무원/사학/국민연금 산식을 구분합니다. 호봉만으로 평균소득을 만들지 않으며 필요한 소득·경과자료가 없으면 금액을 보류합니다. 입력한 공식 조회액의 진위를 앱이 검증하지 않습니다.
- 퇴직수당의 전체 공무원 평균 기반 시나리오는 개인 소득·교사 평균·실제 지급범위가 아닙니다. 구기간 현가자료가 부족하면 전체액을 생성하지 않고 사학·국민연금에 공무원 통계를 자동 적용하지 않습니다.
- 월연금·일시금·분할 재원·조건부 연금계좌를 구분하고 중복 합산하지 않습니다. 생활비 차이는 확인된 월액만 비교하며 정확한 부족액·세후액·계좌 월 인출 가능액을 확정하지 않습니다.
- **법령 구조와 코드 산술 검증은 기관의 실제 개인별 지급액 대조와 다릅니다. 외부 금액 검증은 미완료입니다.**

## 실행·검사 (PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:browser
npm.cmd run build
```

로컬 주소는 http://127.0.0.1:3000 입니다. 단위 테스트는 현재 Node.js26의 TypeScript 직접 실행을 사용합니다. 브라우저 검사는 설치된 Microsoft Edge에서 데스크톱·모바일 에뮬레이션으로 실행합니다. 실제 휴대폰·Safari 점검은 별도입니다. ESLint는 설정되어 있지 않습니다.

최신 로컬 검증: 타입 검사·단위297개·브라우저114개·프로덕션 빌드 통과. 자세한 범위와 한계는 [UI 개선 및 통합 검증](docs/simple-ui-final-improvement.md), [최종 출시 감사](docs/final-release-audit.md), [이번 업데이트 점검](docs/release-update-check.md)을 확인하세요.

## 코드와 배포

진입점은 src/components/simple-planner.tsx, 공통 계산·검증·요청문 연결은 src/lib/simple/, 화면은 src/components/simple/입니다. 기존 src/lib/finance/와 src/lib/ai/ 엔진·이전 컴포넌트는 보존합니다. 기존7메뉴 시나리오는 tests/legacy-browser/에 보존되어 현재6메뉴 E2E에 포함되지 않습니다.

기존 GitHub 저장소의 main 브랜치와 기존 Vercel 프로젝트를 사용합니다. 새 프로젝트를 생성하지 않습니다. Git 커밋·Push·배포는 사용자의 명시적 지시가 있을 때만 수행하며 Vercel 실제 상태는 GitHub 커밋의 Vercel 체크와 기존 프로젝트의 Deployments에서 확인합니다.
