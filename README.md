# 교사 자산 플래너

교사의 은퇴자산 통합 관리를 위한 Next.js App Router · TypeScript · Tailwind CSS 프로젝트입니다.

## 1단계 구현

- 한국어 반응형 대시보드와 메뉴
- 학교 구분, 생년월일, 최초 임용일, 특수 경력 입력
- 학교 구분에 따른 공무원연금·사학연금 표시
- 정밀 계산 모드 및 미구현 메뉴의 준비 중 안내

현재 금융 계산, 인증, 서버 저장은 구현 전입니다. 입력은 화면 메모리에만 유지되며 새로고침 시 초기화됩니다. 예시 금융 금액은 표시하지 않습니다. 특수 경력은 계산에 반영되지 않습니다.

## 2단계 공적연금 입력

- 기존 `공적연금·퇴직수당` 메뉴에서 공무원연금·사학연금별로 월연금과 공식 예상 퇴직수당을 직접 입력합니다. 교사 기본정보의 가입제도·날짜·특수 경력과 연동하며 제도별 금액은 따로 유지합니다.
- 월연금은 공식 조회값과 사용자 추정값을 구분합니다. 공식 조회값도 사용자가 직접 입력한 값이며 기관 조회·진위 검증을 수행하지 않습니다.
- 원·만 원, 세전·세후, 조회 기준일, 산정 시 가정한 퇴직일, 연금 지급개시일 및 추가 가정을 함께 표시합니다. 필수 정보가 유효해야 결과 금액이 표시되며 미입력은 0원이 아닙니다. 단위 변경은 같은 금액을 유지하고 세전·세후 변환은 하지 않습니다.
- 퇴직수당 자동 계산 준비 영역은 인정 재직기간·최종 기준소득월액·2009년 이전 재직·특수 경력을 기록합니다. 산식·예외 검증이 남아 있어 자동 계산 금액은 표시하지 않습니다. 명예퇴직수당은 별도 급여입니다.
- 메뉴·로고 이동 시 입력은 유지되고 새로고침하면 초기화됩니다. Supabase·서버·브라우저 저장소는 연결하지 않습니다. 정밀 계산 모드는 준비 중입니다.
- 데이터 타입은 `src/lib/finance/pension-input.ts`, 금액 단위·날짜·기간 검증은 `src/lib/finance/pension-input-validation.ts`, 화면은 `src/components/pension-panel.tsx`로 분리했습니다.

## 퇴직수당 자동 계산 검증 및 판정

- 공무원·사학 제도별 순수 판정 함수를 분리하고, 자동 계산용 퇴직일·계산 기준일·인정기간 출처·감액 여부·기존 수당 수령 이력을 추가했습니다. 최초 임용일과 특수 경력은 기본정보를 참조합니다. 공식 조회액과 자동 계산 입력은 별도로 유지합니다.
- 2026-11-07 재조사에서 지급비율·33년 상한을 확인했지만, 관련 부칙·급여 끝수 처리·공식 숫자 사례 대조를 완료하지 못했습니다. **현재 자동 계산 가능 범위는 없으며, 양 제도 모두 비활성화합니다.** 금액 산식을 임의로 구현하지 않았습니다.
- 판정 결과는 `amountWon: null`, `appliedMonths: null`, `appliedRate: null`로 반환합니다. 입력한 개월수·소득은 검토 정보로만 표시하며 참고 상한·지급비율을 실제로 적용했다고 표시하지 않습니다. 1년 미만도 0원으로 바꾸지 않습니다.
- 기존 월연금·공식 퇴직수당 입력은 계속 사용 가능합니다. 자동 결과에는 차단 사유·검토 법령과 시행일·계산 기준일·미반영 사항·안내문을 표시합니다. 원 미만 급여 반올림·절사는 미검증 상태이므로 실행하지 않습니다.
- 검증 기록·공식 출처·미확인 목록은 `docs/pension-calculation-research.md` 제10절에 있습니다. 테스트는 입력·차단·경계 동작을 검증하며 **법적 지급액 정답 검증을 대체하지 않습니다.**

## 로컬 실행 (VS Code PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 http://127.0.0.1:3000 을 여세요. 종료는 터미널에서 Ctrl+C를 누릅니다. Windows 실행 정책을 변경하지 않도록 npm.cmd를 사용합니다.

## 검사

```powershell
npm.cmd run typecheck
npm.cmd run build
```

금융 계산 엔진은 `src/lib/finance/`에 UI와 분리하여 추가하고, 실제 계산 함수 구현과 함께 금융 단위 테스트를 추가합니다. 현재 금융 계산 함수는 없습니다. 기본정보 모델은 `src/lib/profile.ts`, 날짜 검증은 `src/lib/profile-validation.ts`에 분리되어 있습니다.

## 기본정보 입력 개선

- 날짜·학교·연금·특수 경력을 React 상태로 관리하여 메뉴 이동과 로고 클릭 시 유지합니다. 새로고침이나 새 탭에서는 초기화됩니다. 브라우저 저장소와 서버에는 저장하지 않습니다.
- 학교 구분은 연금 기본값만 제공합니다. 실제 가입 제도를 직접 선택할 수 있고, 직접 선택한 값은 학교 변경으로 덮어쓰지 않습니다.
- 군 복무·육아휴직·기타 휴직·과거 재직기간 합산은 복수 선택할 수 있습니다. 상세 경력 입력 및 계산 반영은 제공하지 않습니다. `specialCareerDetailsEntered`는 상세 기간 등의 입력 여부이며 단순 경력 선택과 구분합니다.
- 날짜는 `YYYY-MM-DD` 문자열로 검증합니다. 윤년·달력·필수 입력·미래 날짜·생년월일과 임용일의 순서를 확인하며 오늘 날짜는 `Asia/Seoul` 기준입니다. 오류는 제출 후 항목 아래 표시되고 수정 시 다시 검증됩니다.

```powershell
npm.cmd test
npm.cmd run test:browser
```

단위 테스트는 현재 환경의 Node.js 26에서 TypeScript 직접 실행 기능을 사용합니다. 브라우저 테스트는 Microsoft Edge가 설치된 Windows 환경을 기준으로 데스크톱과 모바일 크기를 검사합니다. 실제 휴대폰 검증을 대신하지는 않습니다.

## 다음 단계

조사 근거와 미확인 사항은 `docs/pension-calculation-research.md`에 기록했습니다. 다음 계산 엔진 구현은 부칙·계수·공식 사례를 추가 검증하고 사용자와 개발 범위를 확인한 후 별도로 진행합니다. 현재는 직접 입력과 자동 계산 준비까지만 제공합니다.

Supabase는 이후 인증 및 사용자별 RLS 정책과 함께 연결합니다. 실제 자산정보 입력 전에 접근 제어를 검증해야 합니다. 비밀키와 사용자 자산정보를 클라이언트 코드 또는 로그에 기록하지 않습니다.
