# 교사 은퇴 플래너 — 로그인 없는 간편 계산

기존 Next.js·TypeScript 프로젝트의 디자인과 계산 엔진을 보존하며 6개 메뉴로 입력 구조를 단순화했습니다. 로그인·Supabase·DB·서버 저장·브라우저 저장소는 사용하지 않습니다. 입력은 최상위 React 상태에만 유지되고 새로고침·창 닫기 시 초기화됩니다.

## 현재 메뉴

1. 교사 기본정보 — 가입 연금제도 3종, 날짜, 호봉·승급월, 군복무 산입 상태, 정년/명퇴와 공통 퇴직일
2. 교직원공제회 — 현재 잔액·향후 월 납입·분할 여부, 연 5% 고정 가정
3. IRP·연금저축 — 계좌별 잔액·월 납입, 연 7%/8% 가정, 환급 재투자 선택(실제 환급 미확인으로 미반영)
4. 퇴직급여 계산 — 접힌 수당 카드, 선택적인 공식 조회액 입력, 명퇴 자격/선정 구분
5. 은퇴설계 종합 — 실제 입력과 결과 카드·구성 그래프·표, 선택적인 공식 월연금 입력
6. AI 분석 요청문 — 기본정보만으로 생성, 6개 목적, 익명화·금액 표시·편집·복사, 외부 자동 전송 없음

학교 구분·휴직/경력 합산 상세·복잡한 상품/수익률/종료일/수령 설정·생활비/연령별 현금흐름 화면은 간편 메뉴에서 제외했습니다. 개인연금·부동산·일반 자산·ISA·부채 기능은 추가하지 않습니다. 정밀 계산은 계속 준비 중입니다.

## 계산 범위

- 공통 퇴직일을 바꾸면 모든 적립 결과를 다시 계산합니다. 제도별 공식 조회값은 조회 당시 가정 퇴직일이 일치할 때만 사용합니다. 숨겨진 다른 제도 입력은 보존합니다.
- 일반 초·중등 62세·학기말 정년은 명시적인 적용 가정입니다. 사립·대학·별도 신분은 실제 정년 확인이 필요합니다. 국민연금은 가입제도만으로 정년을 확정하지 않고 직접 입력합니다.
- 호봉은 승급 제한 없는 연간 일정의 조건부 참고정보입니다. 당일/이미 지난 승급은 중복 반영하지 않고 표상 40호봉까지 계산합니다. 근가호봉·특별승급 등은 제외합니다. 2026 봉급표는 참고일 뿐 미래 봉급이나 기준소득월액·수당 산정 소득이 아닙니다.
- 공제회는 공식 급여금이 아닌 가정 적립·분할 모델입니다. 분할은 매월 25일을 선택한 일정 가정이며 실제 전환·휴일·세금·끝수는 별도 확인해야 합니다.
- IRP·연금저축은 완료 월마다 월복리 수익 후 월 납입, 원 단위 반올림을 적용합니다. 세금·수수료·환율은 미반영이며 원금손실이 가능합니다. 실제 환급액을 0원으로 확정하거나 추가 자산으로 넣지 않습니다.
- 공적연금·퇴직수당·명퇴수당의 미검증 자동 금액 산식은 활성화하지 않습니다. 국민연금 가입자에게 공무원/사학 퇴직수당을 적용하지 않습니다.
- 월연금·일시금·분할급여·계좌 적립금은 구분하며 누락을 0원으로 채우지 않습니다. 서로 다른 세금 기준의 수당은 합산하지 않습니다.

공식 자료와 미검증 범위, 모듈 구조·테스트 대응은 [간편 모드 개편 기록](docs/simple-mode-redesign.md)을 참조하세요.

## 실행·검사 (PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:browser
npm.cmd run build
```

로컬 주소는 http://127.0.0.1:3000 입니다. 브라우저 검사는 설치된 Microsoft Edge에서 데스크톱/모바일 설정으로 실행합니다. 실제 휴대폰 점검은 별도입니다. 단위 테스트는 현재 Node.js 26의 TypeScript 직접 실행을 사용합니다.

## 코드 보존

현재 진입점은 `src/components/simple-planner.tsx`, 타입·검증·순수 계산·설정·AI 변환은 `src/lib/simple/`, 화면은 `src/components/simple/`에 분리합니다. 기존 `src/lib/finance/`·`src/lib/ai/` 엔진과 이전 화면 컴포넌트는 삭제하지 않았습니다.

이전 7메뉴 UI만을 대상으로 한 브라우저 시나리오는 `tests/legacy-browser/`에 내용 그대로 보존했습니다. 현재 제품 화면에는 적용되지 않아 기본 브라우저 테스트에 포함하지 않습니다. 기존 계산 모듈의 단위 테스트는 계속 실행합니다. 이전 사용 설명은 [7메뉴 기록](docs/legacy-seven-menu-readme.md)에 보존했습니다.

Supabase 설계 문서는 향후 참고 자료이며 실제 연결은 보류합니다. 금융정보를 로그에 남기지 않습니다. Git 커밋·푸시는 사용자 승인 후에만 진행합니다.
