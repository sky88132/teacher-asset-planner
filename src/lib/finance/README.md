# 금융 계산 엔진

공무원연금과 사학연금은 별도 모듈로 구현할 예정입니다. 공식 자료, 시행일, 경과규정 확인 후 계산과 단위 테스트를 함께 추가합니다. 원 단위 정수·명시적 반올림을 사용하고 세전·세후 및 명예퇴직수당·퇴직수당을 구분합니다.

현재 `pension-input.ts`는 제도별 입력 타입과 빈 초깃값, `pension-input-validation.ts`는 원·만 원의 정확한 환산 및 날짜·준비 입력 검증을 제공합니다. 급여·세금 산식은 구현하지 않습니다. 빈 금액은 `null`이고 명시적 0원과 다릅니다. 만 원은 소수 넷째 자리까지 허용하며 원 미만이나 안전 정수 범위를 넘는 입력은 반올림하지 않고 거부합니다.

공식 조회값과 사용자 추정값은 출처를 구분해 표시하며 조회일·퇴직 가정·세전/세후가 없는 금액은 결과로 표시하지 않습니다. 제도 변경 시 값의 소속을 바꾸지 않고 제도별 입력을 유지합니다. 준비 입력을 완료해도 자동 계산 결과는 계산 불가입니다. 근거와 미확인 사항은 `docs/pension-calculation-research.md`를 따릅니다.
